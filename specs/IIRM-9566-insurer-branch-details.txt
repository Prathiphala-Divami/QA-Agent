PRODUCT SPECIFICATION
=====================
Feature   : Insurer Branch Details - Add / Manage Insurer Enhancement
Story     : IIRM-9566
Date      : 2026-06-20
Stakeholders: Madhav (12-May-2026), Surya (13-May-2026)


1. BUSINESS PROBLEM
--------------------
Insurer details must capture Branch-level information because all IRDAI / Regulatory
bodies prefer to transact with specific branches. The current "Address Details" section
does not reflect business context. Wording, structure, and fields must all be updated.


2. MANAGE INSURER — LIST / SEARCH PAGE
----------------------------------------

2.1 Filter Bar
  - Filters (in order): Organisation, Insurer Name (searchable dropdown),
    Branch Type, Branch Name (searchable dropdown), Branch Code (searchable dropdown), City

2.2 Results Table
  - Columns must match filter sequence:
    Org. | Insurer Name | Branch Type | Branch Name | Branch Code |
    Address | City | State | Phone

2.3 KPI Cards
  - Existing KPI cards must respect applied filters
  - New KPI cards to add (BizDone logic, filter-aware):
      • Total active policies with insurer
      • Premium value
      • Brokerage


3. ADD / EDIT INSURER FORM
---------------------------

3.1 Insurer Details Section
  Fields:
    - Insurer Name
        • Add mode  : User text input
        • Edit mode : Read-only, no editing allowed
    - Display Name  : Editable in both Add and Edit
    - Insurance Company Type (dropdown — existing, continue as-is):
        • Life Insurance
        • General Insurance
        • Health Insurance
        • Non-Life
        • Reinsurance
        • Inactive - Composite Insurance
    - Type of Company (new dropdown):
        • PSU
        • Private
    - Company Tag   : Default = "Company", disabled field
    - Logo          : Continue as-is

3.2 HQ Details Section  (New Section)
  Fields:
    - Branch Type   : Default = "HQ", non-editable
    - Branch Code   : User input
    - Branch Name   : User input
    - Address Fields: Continue as-is (no change)
    - Branch Contact (treated as one contact; more can be added via "Add Insurer Contact"):
        • Contact Name  (NEW field)
        • Other contact fields: continue as-is

3.3 Branch Details Section  (replaces old "Address Details 1")
  Fields:
    - Branch Type (dropdown):
        • CO  - Corporate Office
        • HO  - Head Office
        • DO  - Divisional Office
        • BO  - Branch Office
        • AO  - Area Office
        • RO  - Regional Office
        • ZO  - Zonal Office
        • SC  - Service Center
        • SO  - Satellite Office
        • FC  - Franchise / Channel Partner Office
        • Facultative Reinsurance Unit
        • India Branch Office
        • Operations Hub
        • Representative Office
        • Treaty Management Unit
        • Underwriting Desk
        (Note: HQ is excluded from this dropdown — it appears only in HQ Details section)
    - Branch Code   : User input
    - Branch Name   : User input
    - Parent Branch : Dropdown — default = HQ address; user can select any existing branch
    - Branch Display Name (auto-computed, read-only):
        = Insurer Name + Branch Code + Branch Name + City
    - Branch Address Concat (auto-computed):
        = Branch Code + Branch Name + City
    - Address Fields: Continue as-is
    - Branch Contact (treated as one contact; more can be added via "Add Insurer Contact"):
        • Contact Name  (NEW field)
        • Other contact fields: continue as-is

3.4 KYC Details Section  (New Section — similar to Company KYC)
  Fields (add based on bandwidth — minimum 3):
    - GST Number
    - TIN Number
    - PAN Number
    - Additional KYC fields (if bandwidth allows — complete KYC section)
